権利・用途

本パッケージに含むのは、Happy eBook が権利を保有すると権利者の代理人が本制作で明示し、読者への公開ダウンロードを許可した中国語原書内の例だけです。許可の範囲は manifest.json に記録された例に限ります。

許可は書籍全体、翻訳、第三者のソフトウェア／素材、フォント、表紙、サービス、または原書外のファイルには及びません。第三者プログラム本体、配布アーカイブ、画像、フォントは収録していません。MCP Python SDK と Hermes Agent のライセンス根拠および扱いは manifest を参照してください。

原書の章／後置資料への対応、XHTML ファイル、pre ブロック番号、原文ハッシュ、除外理由は manifest にあります。教材 ZIP 未取得かつ追加ライセンスなしと確認されたため、back-02 の3例は除外しました。これは法律意見ではありません。

例は原書の中国語表記を保持しており、日本語訳または現在のソフトウェア版との互換性を保証しません。インストール、設定変更、外部通信、スケジュール登録などを行う例があります。実行前に内容と対象環境を確認し、秘密情報や実データを使用しないでください。
