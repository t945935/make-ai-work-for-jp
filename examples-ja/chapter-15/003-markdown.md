# イベントデータの確認契約
データソースは sessions.csv のみとし、ネット検索も列の捏造もしない。
定員超過：registered が capacity を上回る場合。超過数は両者の差。
担当者不足：status が confirmed と完全一致し、owner の空白を除いた値が空の場合。
draft は担当者不足に含めない。ただし最終報告でこの除外ルールを説明する。
ID はそのまま保持し、ソースファイルを変更しない。
A は capacity.md のみ、B は ownership.md のみ、主エージェントは final.md のみを書き込む。
各サブレポートにはルール、該当 ID、ソース列、未判定事項を記載する。
